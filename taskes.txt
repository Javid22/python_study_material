## 🟢 Task 4: Dot Product (Core Concept)

### Goal

Measure similarity.

### Formula

[
A \cdot B = \sum A_i B_i
]

### Task

Compute dot product between two movies.

```python
a = np.array([8.8, 2300000, 829, 148])
b = np.array([8.6, 1900000, 701, 169])

dot = np.dot(a, b)
```

### Observation

Dot product grows with size → still biased without normalization.

---

## 🟢 Task 5: Cosine Similarity (Real-World Use)

### Goal

Find **similar movies**.

### Formula

[
\cos(\theta) = \frac{A \cdot B}{||A|| \cdot ||B||}
]

### Task

Implement cosine similarity.

```python
similarity = np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
```

### Interpretation

* `1.0` → identical
* `0.8+` → very similar
* `0.5` → weak similarity

---
